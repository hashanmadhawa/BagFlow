# BagFlow  
**BagFlow — Smart Luggage Transportation & Storage Platform** 
BagFlow is a web-based platform that makes it easier for travellers to transport and temporarily store their luggage between different locations. 
The platform connects**travellers, verified bag holders, and verified bag transporters** in one system. Travellers can create a request by providing their luggage details, pickup location, destination, and required storage period. Verified bag holders can accept requests and securely store the luggage for the requested period, while verified transporters handle the movement of luggage between locations.  
A traveller can also **extend the storage period or transfer their luggage from one bag holder to another** whenever needed. The system maintains a complete movement history of the luggage, allowing the traveller to see where their bags have been stored and transported.  
An **admin dashboard** allows administrators to verify bag holders and transporters, manage users, monitor active requests, and oversee the overall operation of the platform.
### Key Features  * Traveller luggage management * Bag transportation requests * Temporary luggage storage * Transfer bags between different storage locations * Verified bag holders and transporters * Transport job management * Storage-period extension * Luggage movement history * Role-based authentication * Admin verification and management dashboard * Storage facility image verification * Real-time request/status updates through the application  ### Technology Stack  **Frontend:** HTML, CSS, JavaScript, Tailwind CSS **Backend:** Node.js, Express.js **Database:** MongoDB, Mongoose **Authentication:** JWT + bcrypt **File Uploads:** Multer
